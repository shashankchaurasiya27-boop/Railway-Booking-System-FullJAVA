# User Manual

## Getting Started

- Run `MainFrame.java` to launch the application.
- For users: Register or login to begin booking.
- For admins: Login with admin credentials to access management features.

## Features

- Book train tickets
- View or cancel bookings
- Admin: Manage trains, routes, bookings, users

## Notes

- All data stored in MySQL database. Update `database.properties` with your credentials.
- For installation instructions, see README.md

## Troubleshooting

- Database connection errors: Check config in `database.properties`.
- GUI not launching: Confirm Java is installed and dependencies are in `lib/`.
