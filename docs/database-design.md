## Tables

- **users**: Stores all user details including credentials and profile
- **trains**: Stores train details and schedule
- **stations**: Master list of stations
- **routes**: Maps routes between stations for each train
- **bookings**: Stores all ticket booking information
- **payments**: Manages payment transaction records

See [database/schema.sql](../src/main/resources/database/schema.sql) for schema definitions.
